## Проверки и качване

`npm test`: 14 тестови файла преминават, включително обработката през backend функцията, разграничаването на двата ЦСКА и липсващите пазари. `npm run check`: синтактичните проверки преминават.

Пакетът съдържа целия проект, включително netlify/functions и netlify/lib. Използвайте същия начин на качване като за 2.45.4 и запазете настроените Netlify променливи. Не качвайте само HTML файловете. След внедряване е нужна повторна проверка през реалния интерфейс с оригиналните имена от 1xBet.

Тази версия поправя установените български съответствия. Тя не означава, че всички турнири или всички Cloudbet пазари са проверени или налични.
