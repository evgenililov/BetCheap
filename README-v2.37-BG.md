# BetCheap v2.37 — поправка на блокиращия age gate

Поправя /compare.html: двата бутона `ageConfirm` и `ageExit` бяха видими, но assets/snap.js нямаше обработчици за тях. Добавен е независим /assets/age-gate.js, който:
- при потвърждение скрива модалния прозорец и записва `betcheap_age_ok=1` в localStorage;
- при повторно отваряне запазва избора;
- при отказ извежда на `about:blank`, без да допуска до сравнението;
- при недостъпен localStorage позволява потвърждение само за текущата страница;
- не зависи от зареждане на 1xBet и Cloudbet API.

## Проверки
node tests/age-gate.test.js — PASS за двата бутона, постоянен избор и блокиран storage.
Chromium DOM interaction — PASS за confirm и exit с блокирано съхранение. Локален HTTP адрес е блокиран от средата; затова Production E2E трябва да се изпълни след deploy.
Cloudbet tests — PASS (локални mock отговори). Реално потвърдено сравнение на два коефициента все още не е доказано.

Потребителският архив е предназначен за ръчно публикуване в основния сайт на Netlify. Преди deploy запазете възможността за rollback към последния Published deploy.
