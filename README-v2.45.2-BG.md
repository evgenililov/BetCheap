# BetCheap v2.45.2 — диагностика на несъвпадащите срещи

## Реална проверка след качването на 2.45.1

На 16.10.2026 публичният `https://betcheap.netlify.app/` връща обновения интерфейс и окончателния партньорски таг. `onexbet?op=catalog-test` потвърждава автентикация и каталог. `cloudbet?op=probe` потвърждава автентикация, 23 EPL събития и един пълен 1X2 пазар сред три проверени събития. Следователно това не е доказан проблем с липсващи ключове.

За първите 10 предстоящи EPL срещи от 1xBet и LIVE Obolon Kyiv–Veres Rivne Cloudbet върна `matched:false, reason:event_not_verified`. Старият отговор съдържа само брой събития и не позволява да се различат различни имена, стартови часове и статуси. Не е потвърдена нито една обща реална среща с цени от двата оператора.

Истински Chromium браузър без подменени API отговори зареди Everton–Chelsea и показа 1xBet цени 3.23 / 3.86 / 2.24 (закръглени до две цифри), без Cloudbet цени и без JavaScript грешки. Това са исторически стойности при проверката, не текущо обещание за цена.

`operator-link` връща HTTP 302 към 1xBet/Cloudbet. При проверения 1xBet мач отваря началната страница: официалният feed доставя event URL с hostname `1xlite-29668.pro`, който не е сред текущите допустими директни операторски хостове. Не е добавен автоматично нов хост и не е измислен event URL. `affiliate-route` върна `{kind:none, verified:false}` за проверената заявка. Партньорското отчитане остава непотвърдено.

## Промени в 2.45.2

- `cloudbet?op=compare` вече дава агрегирана причина `diagnostic.matchFailure`: празен турнир, липсващ формат на имената, несъвпадащи отбори, несъвпадащ начален час, различен/спрян статус или повече от един кандидат.
- Връща само числови броячи, контролирана причина и разлика в минутите. Не връща raw fixtures, Event IDs, ключове или други вътрешни полета.
- Правилата за съвпадение и отказ при неяснота остават същите. Тази версия е диагностична стъпка, не твърдение, че причината вече е поправена.
- Интерфейсът показва конкретната причина с разбираем текст и показва „—“ за липсващите цени вместо празни клетки.

## Проверки

`npm test`: 10 тестови файла успешни, включително причините за отказ и HTTP отговор без чувствителни данни.

`npm run check`: успешна синтактична проверка.

Браузърна регресия с тестови API данни: сравнение, операторски линкове, LIVE refresh и видими маркери за липсващите цени. Тестовите данни не се добавят в runtime приложението.

## Следваща стъпка

Разгърни 2.45.2 в съществуващия Netlify проект със съществуващите API настройки. Увери се, че се обновяват и функцията `cloudbet`, и `assets/snap.js`, не само HTML страниците. При следващата проверка една от същите реални заявки трябва да върне новите полета в `diagnostic`. Това ще покаже точната следваща поправка, без автоматично съпоставяне на различни срещи.

Не сменяй API ключове само заради `event_not_verified`: автентикацията вече е проверена успешно. Не са активирани нови affiliate маршрути и не е извършен Netlify deploy от тази среда.
