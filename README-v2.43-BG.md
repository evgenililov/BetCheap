## Проверки и ограничения
Локално: node --test tests/*.test.js — 10 успешни тестови резултата, 0 грешки. Тестовете на API използват симулирани отговори. Това не доказва работещ Cloudbet production feed.

Последният production Cloudbet probe върна cloudbet_timeout на етап catalog. Промяната за по-лек каталог на срещите от v2.42 е включена без допълнителни изменения. Тя засяга competition заявката и НЕ доказва отстраняване на timeout при catalog. Няма потвърдено сравнение на действителен еднакъв мач между двата оператора.

Не са променяни affiliate маршрути, секрети или approval flags. Не е извършван deploy. Няма пълна браузърна проверка на този локален пакет и всички негови функции.

## Едно общо публикуване
Използвайте съществуващия начин за публикуване на целия Netlify проект, който изгражда и netlify/functions. Не качвайте само HTML/статичните файлове. netlify.toml трябва да остане в корена, а съществуващите Environment Variables да се запазят.

След едно общо публикуване проверете /compare и /compare.html: възрастово потвърждение, спортове, грешки в конзолата, Upcoming/LIVE. Cloudbet се проверява на /.netlify/functions/cloudbet?op=probe. Ако пак има timeout, не представяйте втория източник като работещ и не замествайте липсващите данни с примерни стойности.
